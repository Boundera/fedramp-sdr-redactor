# Code of Conduct

Be kind, be specific, and assume good faith.

- Discuss the work, not the person.
- Give reasons with disagreements and evidence with bug reports.
- Never post a real Security Decision Record, or any data from one, in an issue, a pull request, or a discussion.
- Respect that maintainers volunteer their time; a closed issue is a decision, not a slight.

Harassment, discrimination, and personal attacks are not tolerated. Report concerns to conduct@boundera.io. Reports are handled privately by the maintainers.
