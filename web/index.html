SDR Redactor

Turn a Security Decision Record into a file you can share. Statuses, FedRAMP identifiers, dates, and counts stay. Names, links, resources, accounts, and narrative text go.

Runs in your browser. Nothing you load here leaves this page. No upload, no account, no analytics on content. Disconnect from the network and it still works.

2. Options

Large numbers, nine digits and up, are always masked. Narrative text is always replaced whole; there is no partial scrubbing to get wrong.

Words you may want to keep

These fields hold a few repeated words, such as a provider or an assurance class. Each one became a token. Tick the words that are safe to show. Only what you tick is kept.

3. Result

    The token map holds the original values. Keep it private.
